# Portofolio Ismail Abbas

Website statis responsif yang dibuat berdasarkan CV Ismail Abbas.

## Cara membuka
1. Ekstrak file ZIP.
2. Buka `index.html` menggunakan browser.
3. Tidak diperlukan instalasi atau server.

## Cara mengubah konten
Semua teks utama, pendidikan, keahlian, pengalaman, sertifikat, proyek, dan kontak berada di:

`site-data.js`

Cari komentar **PUSAT EDIT KONTEN** lalu ubah nilai di dalam tanda kutip.

## Bagian yang masih berupa placeholder
- Sertifikat formal
- Teknologi/alat pada proyek
- Tautan GitHub proyek
- Akun GitHub
- Media sosial lain

Placeholder sengaja dipertahankan karena data tersebut tidak tercantum di CV.

## Mengganti foto
Ganti file berikut dengan foto baru menggunakan nama yang sama:

`assets/profile-ismail.jpg`

## Mengganti CV
Ganti file:

`assets/CV_Ismail_Abbas.docx`

Pastikan nama file tetap sama agar tombol **Download CV** terus berfungsi.

## Struktur
- `index.html` — struktur halaman
- `styles.css` — desain dan responsivitas
- `site-data.js` — pusat data yang mudah diedit
- `app.js` — rendering konten, navigasi mobile, dan animasi
- `assets/` — foto, CV, dan favicon
